### 📌 Featured Project

#### 🩺 [SwasthyaSeva — AI-Powered Healthcare Intelligence Platform](https://github.com/Neerajkr2/SwasthyaSeva)
A deployed full-stack platform that turns complex medical data into simple, actionable insight.
- AI symptom analysis + real-time health chatbot (**Anthropic Claude API**, Hugging Face NLP)
- OCR-based medical-report interpretation, disease-risk prediction (Random Forest, Gradient Boosting), drug-interaction detection
- Secure auth (Firebase + reCAPTCHA), personalized dashboard, protected REST APIs

**Stack:** React · Vite · Tailwind · FastAPI · PostgreSQL · SQLAlchemy · Python ML

🔗 **Live:** https://swasthyaseva.vercel.app/ &nbsp;|&nbsp; 💻 **Code:** https://github.com/Neerajkr2/SwasthyaSeva
